# Contributing to buildpipe

Thanks for your interest in contributing.

## Getting Started

1. Fork the repo and create your branch from `main`.
2. Install dependencies: `npm install`
3. Run in development mode: `npm run dev`

## Making Changes

- Keep changes focused — one feature or fix per PR.
- Test your changes manually before submitting.
- Follow the existing code style (vanilla JS ES modules, no frameworks).

## Pull Requests

- Write a clear PR title and description explaining what and why.
- Link any related issues.
- PRs that break existing functionality will not be merged.

## Reporting Bugs

Open an issue with:
- Steps to reproduce
- Expected vs actual behaviour
- OS and app version

## Code of Conduct

Be respectful. Harassment or hostile behaviour of any kind will not be tolerated.
